# MailFlow

Automated Email Marketing Platform with Analytics

## Overview

MailFlow is a MERN Stack web application that enables businesses and marketers to create, manage, automate, and analyze email marketing campaigns. The platform provides customizable email templates, customer segmentation, automated campaign workflows, and detailed analytics to help improve customer engagement and campaign performance.

## Features

- User Authentication
- Create and Customize Email Templates
- Create and Manage Email Campaigns
- Automated Email Workflows
- Customer Segmentation
- Campaign Scheduling
- Email Delivery using SendGrid
- Track Email Open Rates
- Track Click Rates
- Campaign Performance Analytics
- User Dashboard
- Responsive UI
